# krotoku.github.io

Персональный или проектный сайт, размещённый на GitHub Pages.

## О проекте

Этот репозиторий содержит исходные файлы веб-сайта и публикуется через GitHub Pages по адресу:

https://krotokuapp.github.io

## Структура проекта

На данный момент репозиторий пустой. По мере разработки в него можно добавить HTML, CSS, JavaScript и другие необходимые ресурсы.

## Локальный запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/krotokuapp/krotoku.github.io.git
cd krotoku.github.io
```

2. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере.

## Публи��ация

Изменения в ветке `main` публикуются автоматически через GitHub Pages после включения Pages в настройках репозитория:

**Settings → Pages → Deploy from a branch → `main` / `(root)`**
